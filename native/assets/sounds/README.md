# native/assets/sounds/

Suonerie custom bundled per sveglie WBTB (Step 4) e cue TLR (Step 4).

Aggiungere qui file `.wav` (formato cross-platform, ≤ 30s, loop-friendly).
Sono referenziati da `capacitor.config.ts` → `LocalNotifications.sound`.

**Niente audio binaural beats** (regola wiki §5.4 + §7.8): nessun claim non supportato.
